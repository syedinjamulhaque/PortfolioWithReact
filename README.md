# Developer Portfolio

A modern, responsive personal developer portfolio built with React and Vite.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS

## Features

- Responsive design
- Skills & Technologies
- Education
- Projects showcase
- Contact section
- Smooth animations

## Run Locally

npm install
npm run dev

## Build

npm run build
